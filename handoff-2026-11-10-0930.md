## Mac gotchas (learned the hard way; `farm-game-check/SKILL.md` §2 has them too)

- Godot: `/Applications/Godot.app/Contents/MacOS/Godot` (4.7). **Every Godot run with a throwaway `HOME=<dir>` and the smoke test and bot with `-- --seed=1`**; otherwise tests overwrite the parent's real save.
- macOS has no `timeout` (use the tool's time limit or `perl -e 'alarm shift; exec @ARGV' 170 cmd`). `check_all.sh` finds Godot by itself. Short suite ≈ 2.5 min, full golden record ≈ 4 min, a bot run to chapter 5 ≈ 2 min.
- Run checks on a copy, not in the folder: `S=<scratch> bash tools/parallel/mkcopy.sh <name>` then `HOME=$S/w/<name>/home $G --headless --path $S/w/<name>/work/godot-prototype --import` once. The docs check needs the whole copy (the script copies it).
- Screenshots open a real window for a few seconds on the parent's screen; keep them few. Flags: `godot-prototype/README.md` "Testing shortcuts" (`--give` before `--pack` before `--square`).
- Merging agent patches: `.uid` and `.import` files are tracked (new scripts and assets bring them); expect hand merges in `README.md`, `tests/ui_smoke.gd`, `tests/ui_driver.gd`, `data/i18n/ui-de.json`.
  New game in a smoke test: close the opening frame with `D.frame_close()` (it is a scene now, `D.close_modal()` does not close it). Pace and goldens differ run to run only by seed; the golden runs are deterministic.
- Never delete files without asking; never edit `archive/`. Agents must not delete either (leave unused files, stop referencing them).
