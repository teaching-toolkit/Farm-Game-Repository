# Hazelwood Harvest (Farm Quiz Game): start here

1. Read `00-READ-ME-FIRST.md` (one page) and `ROADMAP.md` (one page).
2. Load the project skill `farm-game-session` (`.claude/skills/farm-game-session/SKILL.md`): what to read per task, the tracker in
   `.scratch/`, the ask-matt flow, git. Before saying a change works: `farm-game-check`. For content: `farm-game-content`.
3. **End-of-session rule, every session and every track:** ticket status, one `PROJECT-LOG.md` row, `ROADMAP.md` only if "Now"
   changed, `docs/design/` when the game's behaviour changed; run `python3 tools/check_docs.py`; end with a commit message.

`web-build/` is not in this repo (a separate public repo, parked).
