# Source map (assembled baseline)



Basis codes: **S** shipped game text · **W** staged game text · **N** no game text (built from the outline seed; sketch lines verbatim where they exist) · **-rev** game text revised as the seed directs · **-bark** an ambient line · **canon** a reference section. All game text is rendered in the third person (convention 1 in `inventory.md`); the original second-person wording is in the last-but-one column.

Seed files: every seed id (`E-…`) lives in one slice dossier, named in the column; the play order is `story/outline/master/chN.md`. Piece versions: every piece exists in one version only (`story/archive/texts/*.md`, identical to git HEAD `story/texts/`, and to the game JSON); older git revisions are listed where the text differed. Seed sections are identical in the run snapshots `story/archive/run-2026-10-23/after-round-0[1-3]/` (no superseded seed text).
