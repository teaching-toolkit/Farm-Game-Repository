## 1. The three dials, for this game

- **Language:** comfortable for a six-year-old; short sentences, second person, nobody talks about the farmer in the third person.
- **Story:** built for an eight-year-old; real costs (the Lord's share, the collapse), a number that turns out to be a person, a secret that stays a little unsaid.
- **Texture:** narration-forward. A game text is a few lines read in a box, so the Willems dialogue ratio does not apply; the Helpers never talk.

## 3. The Keeper's moves

Each new piece carries one *Move*, the thing a good dungeon master does when the table does something for the first time.

| Move | What it does | Typical trigger |
|---|---|---|
| **Arrival** | Names a place or thing the player just touched, with one odd detail | a tap, a first build |
| **Reward** | Pays a deed with a sensory moment, not a number | a finished dish, a harvest |
| **Level-up** | Marks a new ability without saying "level" | tool, bench, card |
| **Complication** | A small snag that makes the success feel real | the first fire, the new barn |
| **Plant** | Lays something the later chapters pay off | the lantern outside, the swing, the tiny light |
| **Omen** | A small sign that something is coming or is watching | pet gifts, the second cup, footprints |
| **Notice** | Berit's margin notes: the dead grandmother talks through the cards | a card is read |
| **Escalation** | Same event as before, heavier by one notch | the Lord's share, each time |
| **Echo** | Rings a bell from earlier | the birthday, the swing occupied, the fire again |

## 5. The motif ladder (💡 invented)

Fire → warmth → roof → bread → lantern → light. Chapter 1 has the first fire, chapter 2 the stove and the kiln, chapter 3 the forge, chapter 4 glass and the greenhouse (light captured), chapter 5 the lamp, chapter 6 the fire again. Same object, a little larger each time.

## 6. What the last chapter does

`c6_eve` lights the first fire of the book again, with the same words as `c1_fire` ("the ash around it glows a little, as if it remembers something"). It does not summarise. The last margin note (`c6_n_last`, `cards>=87 + seen:c6_supper`) closes Berit's voice: "Go and put the kettle on, my love."
