# The story bible is canon

`canon/story-bible.md` settles the facts. Where a character, world or outline file disagrees, the bible wins and the other file is
corrected. The parent's rulings of 24 Oct 2026 are listed in the bible's §10; the manager rulings of the outline run (R-M1 to R-M11)
are in `archive/slices/DECISIONS.md`.
