# Awe is rare: five moments in the game

Moments of awe are capped (at most two a chapter, eight in all) and the game uses five: the first night, the Wall, the white spiral,
the night garden's first sight, the glowing stones on frame 6's sill. Everything else is warmth or a gag. (R-M2, 24 Oct 2026; the
count is still an open question for the parent, 00-4a.)
