# Round 8 pictures: which file name for which sheet

version of each sheet, download it and save it here in `art-inbox/` under the name in the first column. Then run
`python3 tools/import_art.py all` in the godot-prototype folder: it cuts every sheet into the pictures listed in
`tools/art_sheets.json` (left to right, top to bottom) — a sheet whose objects are in the wrong order or missing one is
better left out (or the object skipped with `-` in art_sheets.json).
