# One farm-actions module prices, checks and pays every chore

Every chore goes through one module: it gives the effective cost and the requirements (the check), and it performs the chore and
returns a report. Coins leave the purse only through the one pay function, which refuses while the Lord's share is owed. Buttons,
the bot and pets all ask the same module, so there are no hand-made copies of prices or "too tired" checks. Built in farm-actions
02–13 (finished 30 Oct 2026); words in `GLOSSARY.md`.
