# The game data wins until a story's data wish is built

When a story text and the game data disagree, the data is right and the text is corrected, unless the story has a data wish the
parent has approved; then the wish is built in the data (`story/game/data-wishes.md`). Story details may change the game's plot events
to fit the story as long as the game's pacing stays roughly sensible (parent, 9 Oct 2026). Touches both areas, so it lives here.
