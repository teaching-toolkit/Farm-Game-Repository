# Reusable kits, but only as general as the farm needs

The reusable parts (avatar and acts, wellbeing, the clock and playback, store and carrying, story pieces, interface parts) live as
kits apart from the farm game, so a spin-off could reuse them. The spin-off is very hypothetical, so a kit is never made more general
than the farm itself needs. (`archive/log-2026-10.md` §2.8, rounds 6–7.)
