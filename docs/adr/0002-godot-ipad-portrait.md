# Godot, iPad portrait first, one screen

The game is built in Godot (the HTML5 prototype is archived), designed for an iPad in portrait, everything on one screen without
scrolling, with an isometric map whose layout is data edited by hand. Reaching the iPad goes through the browser export. Decided in
rounds 1.3 to 1.3.3 (`archive/log-2026-10.md` §2.4–2.5). For now the parent play-tests on the laptop (ADR-0001).
