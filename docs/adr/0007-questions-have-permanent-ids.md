# Questions have permanent ids; one learning record per child

Every Time Quiz question has an id that is never changed or reused, so a child's record survives rewording and translation. Learning
lives in a reusable learning kit with one plain JSON record per child that a parent can read and edit. Medals are bronze, silver and
gold; there are no leagues and no breakable daily streaks. (`archive/log-2026-10.md` §2.5, rounds 1.3.7–1.3.8.)
