# Price table (D3, 13 Oct 2026)

Every item's value in **bronze** (100 bronze = 1 gold; like Rappen and Franken). *Before* = the old coins ×1; *After* = what the game uses now. Most things are the old value × 15 (the same ratios, so the pace of the game is unchanged); the ones with a note are set to a realistic Swiss price. Made by `tools/rescale_prices.py`; change a price in `data/farm/items.json` and re-run the checks.

Also scaled ×15: every coin cost of goals, steps, animals, books, seeds (`seedCost`), what merchants sell for, coin barter, the start coins, the lost coin in the weeds and the little jobs' reward (120 nodes' costs, 18 seed prices, 11 merchant prices).
